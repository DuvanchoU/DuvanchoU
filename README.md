## 🔍 Proyecto principal

👉 **[DUFEX](https://github.com/DuvanchoU/sistema-dufex)**  
**Sistema de gestión comercial** desarrollado en **Laravel**, orientado a pymes del sector muebles.

### 🧩 Algunas funcionalidades implementadas:

- 📦 **Gestión de inventario** con control de stock real y comprometido  
- 💰 **Ventas, cotizaciones y compras** con relaciones normalizadas  
- 👥 **Usuarios, roles y permisos** mediante **Spatie Laravel Permission**  
- 🗑️ **Soft Deletes** para recuperación y trazabilidad de registros  
- 🛡️ **Validaciones desacopladas** usando **Form Requests**  
- 🌙 **Modo claro / oscuro** con Tailwind CSS  
- 🔐 Enfoque en **seguridad, integridad de datos y lógica de negocio**  
- 🧱 Arquitectura basada en **MVC, POO y buenas prácticas**

DUFEX es un proyecto en constante evolución y refleja mi crecimiento como desarrollador backend, enfrentando problemas reales y tomando decisiones técnicas pensadas para sistemas escalables.
